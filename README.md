# Двое — на одной волне

Адаптивный личный журнал о дуэте. Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion и Lucide.

## Запуск

Требуется Node.js 20.9 или новее. В облачной среде используется Node.js 24.

```sh
cd /workspace/probnik
npm ci --no-audit --no-fund
npm run dev
```

Сервер запускается на порту 3000. Для production: `npm run build`, затем `npm start`.

## Проверки

```sh
npm run typecheck
npm run build
npm run test:e2e
```

Для браузерных тестов используется системный `/usr/bin/chromium`, если он установлен. В других средах предварительно выполните `npx playwright install chromium`. Тесты охватывают desktop/mobile, навигацию, диалоги, галерею, фокус клавиатуры, выбор настроения, гостевую книгу, звук, reduced motion и горизонтальное переполнение на пяти ширинах.

## Структура

- `src/app/page.tsx` — секции и пользовательские сценарии.
- `src/components/ui.tsx` — повторно используемые анимации и доступные диалоги.
- `src/lib/content.ts` — тексты историй и ответы линии связи.
- `src/app/globals.css` — визуальные токены и адаптивная система.
- `public/images/duo.png` — художественная версия предоставленных фотографий, созданная с помощью генерации изображения. Это не исходная фотография.
- `public/fonts` — локальные Manrope и Cormorant Garamond с лицензиями SIL OFL.

Имена персонажей и биографические факты не были предоставлены. Тексты историй — редакционные миниатюры, а не утверждения об их реальной жизни.

Гостевая книга и сердечко сохраняются только в localStorage текущего браузера. Сообщения не передаются героям и не синхронизируются между устройствами. «Звонок» — интерактивный сценарий, не телефонная связь. Звук создаётся через Web Audio только после нажатия. Серверные секреты и внешние API не требуются.

## Облачная среда

Используйте существующий checkout `/workspace/probnik`; отдельный worktree не нужен. После восстановления среды процессы требуется запустить заново командой `npm run dev`. Установка использует lockfile; npm-кеш находится в `/tmp/probnik-npm-cache`.

## Публикация на Vercel

Файл `vercel.json` задаёт Next.js, установку по lockfile и production-сборку. `.vercelignore` исключает зависимости, результаты сборки, тестовые артефакты и локальные секреты из загрузки.

Для размещения необходим доступ к аккаунту Vercel. В облачной среде добавьте `VERCEL_TOKEN` через защищённые настройки секретов; не вставляйте токен в исходники или сообщения. Сетевой доступ требуется к `api.vercel.com` для публикации и к адресу проекта на `*.vercel.app` для проверки результата.

На собственном компьютере можно опубликовать проект через интерактивную авторизацию:

```sh
cd /path/to/probnik
npx vercel login
npx vercel deploy --prod
```

После размещения проверьте главную страницу, портреты, диалоги и мобильное меню по выданному Vercel URL. Сохранение локальной конфигурации не означает, что сайт уже опубликован.
